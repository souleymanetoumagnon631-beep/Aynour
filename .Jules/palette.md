## 2025-05-18 - Explicit Label Associations & ARIA Labels in HTML Order Forms
**Learning:** Single-page landing page forms often rely on visual layout adjacency rather than explicit `for` attributes on `<label>` elements or accessible names on quantity `-`/`+` buttons, which degrades screen reader accessibility.
**Action:** Always check form labels for matching input `for` attributes and ensure quantity stepper buttons carry descriptive `aria-label`s.
