# Palette's Journal

## 2025-05-18 - Form Labels & Accordion ARIA Improvements
**Learning:** Pure HTML landing pages without JS framework libraries often miss implicit label bindings and dynamic `aria-expanded` states on custom accordions.
**Action:** Ensure all `<label>` tags explicitly reference input `id`s with `for`, add `aria-label` to icon/symbol-only buttons, and sync `aria-expanded` attributes on interactive disclosures.
